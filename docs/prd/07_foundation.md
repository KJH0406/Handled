# 07. 공통 기반 (Foundation)

모든 페이지가 공유하는 전역 기반(언어, 전역 내비·푸터, 화면 이동, 통화·날짜 표기, 에러·없음 화면)을 한곳에 정의해 도메인 문서가 중복 없이 참조하게 한다.

| 항목            | 내용                                                                                                                                                                                                            |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상태**        | 🟡 초안(검토 요청)                                                                                                                                                                                              |
| **작성 기준**   | 현재 구현된 동작 기준 (미구현·정책 공백은 섹션7에 분리)                                                                                                                                                         |
| **관련 라우트** | 전역(모든 페이지) · 에러 화면 · 404(없음) 화면                                                                                                                                                                  |
| **범위 메모**   | 이 문서는 제품 레벨의 전역 공통 동작(언어·내비·푸터·통화·날짜·에러·404 등)만 다룬다.                                                                                                                            |
| **관련 PRD**    | 모든 도메인 문서가 이 문서를 참조한다([home](./02_home.md) · [planner](./03_planner.md) · [experience](./04_experience.md) · [stories](./05_stories.md) · [my-plans](./06_my-plans.md) · [auth](./01_auth.md)). |

## 1. 기능 배경 및 목적

### 배경 / 문제

페이지마다 내비게이션, 통화·날짜 표기, 에러 처리 같은 공통 요소를 따로 정의하면 서로 어긋나고 중복된다. 이 문서는 그 공통 기반을 한곳에 모아 일관성을 보장하고, 각 도메인 문서가 "여기서 정의됨"으로 참조하게 한다.

### 목적 / 목표

- **일관성:** 어느 페이지에서나 동일한 내비·통화·날짜·에러 경험을 제공한다.
- **영어 단일 제공:** MVP는 영어로만 제공한다(언어 선택·다국어 미지원). 다국어 확장은 향후 검토(→ 섹션7).
- **회복력:** 오류·잘못된 주소에서도 막다른 길 없이 복귀 경로를 제공한다.

### 성공의 정의 · 비목표(Non-goals)

- **성공:** 사용자가 어떤 페이지에서도 길을 잃지 않고 이동·복귀할 수 있고, 금액·날짜가 일관되게 보인다.
- **비목표(이번 범위 밖):** 실시간 환율, 도움말/약관 등 정적 페이지, 오류 모니터링 연동. (→ 섹션7)

## 2. 유저 스토리 (User Story)

**페르소나:** **여행자(Traveler)** - Handled로 한국 여행을 계획·예약하는 사람.

| ID        | 스토리                                                                                                     |
| --------- | ---------------------------------------------------------------------------------------------------------- |
| US-FND-01 | 여행자로서, 어느 페이지에서나 같은 내비게이션으로 주요 영역(플래너·경험·스토리·내 일정)으로 이동하고 싶다. |
| US-FND-02 | 여행자로서, 금액과 날짜가 일관된 형식으로 표시되길 원한다.                                                 |
| US-FND-03 | 여행자로서, 잘못된 주소로 들어가면 "없음" 안내와 돌아갈 길을 받고 싶다.                                    |
| US-FND-04 | 여행자로서, 오류가 나도 다시 시도하거나 홈으로 돌아갈 수 있길 원한다.                                      |
| US-FND-05 | 여행자로서, 푸터에서 제품·회사·지원 정보를 찾고 싶다.                                                      |

## 3. 핵심 사용자 플로우

**A. 전역 이동**

1. 어느 페이지에서나 상단 내비로 플래너·경험·스토리로 이동하거나 로고로 홈으로 간다.
2. 계정 메뉴에서 내 일정·로그인/로그아웃에 접근한다(→ [auth](./01_auth.md)).

**B. 오류·복귀**

1. 잘못된 주소 → "없음" 화면 → 홈으로.
2. 렌더 오류 → 오류 화면 → 다시 시도 또는 홈으로.

## 4. 영역별 기능 정의 및 정책

### 4.1 언어 (영어 단일)

- **목적:** MVP는 영어로만 화면을 제공한다.
- **정책 · 규칙:**
  - **단일 언어:** 화면은 영어로만 제공하며, 언어 선택기·자동 언어 감지·언어별 주소는 두지 않는다.
  - **다국어 확장:** 한국어 등 추가 언어 지원은 향후 검토한다(→ 섹션7).
- **상태별 표시:** 영어 단일.

### 4.2 전역 내비게이션 (상단)

- **목적:** 어디서나 주요 영역과 계정 동작에 접근하게 한다.
- **구성 · 주요 기능:**
  - **로고:** 홈으로.
  - **탭:** 플래너 · 경험 · 스토리. 현재 위치한 영역은 활성 표시.
  - **계정 영역:** 비로그인은 "로그인" + 계정 아이콘, 로그인은 계정 메뉴(이름·이메일·내 일정·도움말·로그아웃). 자세한 계정 동작은 [auth](./01_auth.md).
  - **모바일:** 탭이 계정 메뉴 안으로 들어간다.
- **정책 · 규칙:**
  - **깜빡임 방지:** 로그인 여부가 확정되기 전에는 로그인/계정 UI 노출을 보류한다(→ [auth](./01_auth.md)).
  - **메뉴 닫힘:** 계정 메뉴는 외부 클릭·페이지 이동 시 닫힌다.
  - **활성 표시:** 현재 영역 탭에 활성 상태를 표시한다.
  - **도움말 링크:** 계정 메뉴의 "도움말"은 현재 연결된 페이지가 없다. → 현재 미구현 상태로 섹션7 참고
- **상태별 표시:** 상태 미확정(보류) / 비로그인 / 로그인 / 모바일.

### 4.3 푸터(\* 섹션7에서 기획 검토 사항 확인 필요)

- **목적:** 제품·회사·지원 정보 묶음과 브랜드 정보를 제공한다.
- **구성 · 주요 기능:** 브랜드(이름·태그라인) + 3개 컬럼(제품 · 회사 · 지원) 링크 + 하단 저작권/태그라인.
- **정책 · 규칙:**
  - 결제 완료 화면에서는 푸터를 숨긴다.
  - **링크 미동작:** 현재 푸터의 모든 링크(제품·회사·지원, 도움말·약관·개인정보 포함)는 실제 페이지로 연결되지 않는다.
- **상태별 표시:** 표시 / (결제 완료 화면) 숨김.

### 4.4 화면 이동 동작

- **목적:** 페이지 전환을 일관되게 한다.
- **정책 · 규칙:**
  - **상단 정렬:** 화면 이동 시 새 페이지를 맨 위에서 보여준다(스크롤을 위로 초기화).
  - **딥링크:** 목록·위저드는 주소의 값으로 초기 상태를 채운다(도시·카테고리·검색어·날짜 등). 각 값의 의미는 해당 도메인 문서(특히 [experience](./04_experience.md)·[planner](./03_planner.md)).
- **상태별 표시:** 해당 없음.

### 4.5 통화 / 날짜 표기

- **목적:** 금액·날짜를 일관된 형식으로 보여준다.
- **정책 · 규칙:**
  - **통화:** 금액은 달러($) 기준으로 보관하고 달러($)로 표시한다.
  - **환율:** 달러 표기는 고정 환율로 산정되며, 실시간 시세는 반영하지 않는다.
  - **날짜:** 날짜·기간은 영어 형식으로 표시한다.
- **상태별 표시:** 달러($) 표기.

### 4.6 에러 화면

- **목적:** 렌더 오류에서도 복귀 경로를 준다.
- **구성 · 주요 기능:** 안내 아이콘 · 제목 · 부연 · "다시 시도" · "홈으로".
- **정책 · 규칙:** "다시 시도"는 화면을 다시 렌더링한다. 오류는 현재 콘솔에만 기록된다(외부 모니터링 없음).
- **상태별 표시:** 오류(복구 액션 제공).

### 4.7 없음(404) 화면

- **목적:** 존재하지 않는 주소에서 막다른 길을 막는다.
- **구성 · 주요 기능:** 안내 아이콘 · 제목 · 부연 · "홈으로".
- **정책 · 규칙:** 잘못된·없는 주소는 404 "없음" 화면으로 안내한다. 여기에는 알 수 없는 경로뿐 아니라 **없는 항목의 id 주소(없는 경험·일정·글 등)도 포함**한다. 목록의 필터·검색 결과가 0건인 "빈 상태"와는 구분한다(빈 상태는 각 도메인 문서에서 다룸).
- **상태별 표시:** 없음(홈 CTA).

| ID        | 관련 US   | 인수 조건 (완성 기준)                                                                                   |
| --------- | --------- | ------------------------------------------------------------------------------------------------------- |
| AC-FND-01 | US-FND-01 | 모든 페이지 상단에 동일한 내비(로고·플래너·경험·스토리·계정)가 있고, 현재 영역 탭이 활성으로 표시된다.  |

## 6. 예외 처리 & 엣지 케이스

| 상황                              | 기대 동작                                               |
| --------------------------------- | ------------------------------------------------------- |
| 알 수 없는 주소                   | "없음"(404) 화면 + 홈 CTA.                              |
| 렌더 오류 발생                    | 오류 화면(다시 시도/홈) 표시, 오류는 콘솔 기록.        |

## 7. TBD / 정책 공백

> 현재 비어 있는 기능 및 정책과 프로덕션 전환 시 결정이 필요한 항목. (결정권자 : CPO)

1. **다국어 확장 (향후)** - MVP는 영어로만 제공한다(언어 선택기·다국어 미지원). 향후 한국어 등 추가 언어 지원 시 언어 선택·자동 감지·번역 자원·통화/날짜 현지화 정책을 함께 정의해야 한다.
2. **푸터 구성·연결 기획 필요 (중요)** - 현재 푸터(제품·회사·지원 묶음)와 계정 메뉴 "도움말"은 **임시 구성**이며 연결된 페이지가 없다. 푸터에 어떤 메뉴를 넣을지(구성)와 각 항목 클릭 시 이동 대상(정적 페이지: 소개·약관·개인정보·고객지원 등)을 함께 정의·연결해야 한다. ([auth](./01_auth.md) 섹션7의 약관 동의와 연계)
3. **404 vs 빈 상태 카피 정합** - 잘못된·없는 주소·id(없는 경험·일정·글 포함)는 404로, 필터·검색 0건은 도메인 빈 상태로 처리하기로 정했다(섹션4.7). 두 경로의 카피·동작이 도메인 문서 간 일관되게 유지되는지 점검 필요.
4. **개인정보·쿠키 동의 및 제품 분석 부재** - 쿠키·개인정보 처리 동의 배너와 제품 사용 분석(이벤트 트래킹)이 없다. 글로벌 서비스에 필요한 동의 흐름·분석 도입 정책 필요.
5. **전역 SEO·메타데이터** - 페이지별 메타(제목·요약)·OG 태그·사이트맵 등 검색 유입·공유용 메타데이터 정책이 전역 차원에서 정의되어 있지 않다. (스토리 등 콘텐츠 SEO도 이 전역 정책을 따른다.)
