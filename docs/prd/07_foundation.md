# PRD - 공통 기반 (Foundation)

**한 줄 요약:** 모든 페이지가 공유하는 전역 기반(언어/지역, 전역 내비·푸터, 화면 이동, 통화·날짜 표기, 에러·없음 화면, 접근성)을 한곳에 정의해 도메인 문서가 중복 없이 참조하게 한다.

| 항목 | 내용 |
| --- | --- |
| **상태** | 🟡 초안(검토 요청) |
| **작성 기준** | 현재 구현된 동작 기준 (미구현·정책 공백은 §7에 분리) |
| **관련 라우트** | 전역(모든 페이지) · 에러 화면 · 404(없음) 화면 |
| **범위 메모** | **디자인 시스템(토큰·컴포넌트·접근성 속성 기준)은 [`/DESIGN.md`](../../DESIGN.md)가 단일 기준**이며 이 문서는 중복하지 않고 제품 레벨 공통 동작만 다룬다. |
| **관련 PRD** | 모든 도메인 문서가 이 문서를 참조한다([home](./02_home.md) · [planner](./03_planner.md) · [experience](./04_experience.md) · [stories](./05_stories.md) · [my-plans](./06_my-plans.md) · [auth](./01_auth.md)). |

## 1. 기능 배경 및 목적

### 배경 / 문제
페이지마다 언어 전환, 내비게이션, 통화·날짜 표기, 에러 처리 같은 공통 요소를 따로 정의하면 서로 어긋나고 중복된다. 이 문서는 그 공통 기반을 한곳에 모아 일관성을 보장하고, 각 도메인 문서가 "여기서 정의됨"으로 참조하게 한다.

### 목적 / 목표
- **일관성:** 어느 페이지에서나 동일한 내비·언어 전환·통화·날짜·에러 경험을 제공한다.
- **다국어:** 영어·한국어를 지원하고, 사용자가 직접 언어를 바꿀 수 있게 한다.
- **회복력:** 오류·잘못된 주소에서도 막다른 길 없이 복귀 경로를 제공한다.
- **접근성:** 디자인 시스템의 접근성 기준([`/DESIGN.md`](../../DESIGN.md))을 전역에서 지킨다.

### 성공의 정의 · 비목표(Non-goals)
- **성공:** 사용자가 어떤 페이지에서도 길을 잃지 않고 이동·언어 전환·복귀할 수 있고, 금액·날짜가 일관되게 보인다.
- **비목표(이번 범위 밖):** 실시간 환율, 브라우저 언어 자동 감지, 도움말/약관 등 정적 페이지, 오류 모니터링 연동, 3개 이상 언어. (→ §7)

## 2. 유저 스토리 (User Story)

**페르소나:** **여행자(Traveler)** - Handled로 한국 여행을 계획·예약하는 사람. 공통 기반은 로그인 여부와 무관하게 모든 사용자에게 적용된다.

| ID | 스토리 |
|---|---|
| US-FND-01 | 여행자로서, 어느 페이지에서나 같은 내비게이션으로 주요 영역(플래너·경험·스토리·내 일정)으로 이동하고 싶다. |
| US-FND-02 | 여행자로서, 언어를 영어/한국어로 직접 바꾸고 보던 페이지를 그대로 보고 싶다. |
| US-FND-03 | 여행자로서, 금액과 날짜가 내 언어에 맞게 일관되게 표시되길 원한다. |
| US-FND-04 | 여행자로서, 잘못된 주소로 들어가면 "없음" 안내와 돌아갈 길을 받고 싶다. |
| US-FND-05 | 여행자로서, 오류가 나도 다시 시도하거나 홈으로 돌아갈 수 있길 원한다. |
| US-FND-06 | 여행자로서, 페이지를 옮길 때 화면 맨 위에서 새 페이지를 보고 싶다. |
| US-FND-07 | 여행자로서, 키보드와 보조기술만으로도 내비게이션과 주요 동작을 쓸 수 있길 원한다. |
| US-FND-08 | 여행자로서, 푸터에서 제품·회사·지원 정보를 찾고 싶다. |

## 3. 핵심 사용자 플로우

**A. 전역 이동**
1. 어느 페이지에서나 상단 내비로 플래너·경험·스토리로 이동하거나 로고로 홈으로 간다.
2. 계정 메뉴에서 내 일정·로그인/로그아웃에 접근한다(→ [auth](./01_auth.md)).

**B. 언어 전환**
1. 언어 선택기를 연다 → 영어/한국어 선택 → 같은 페이지가 선택 언어로 다시 표시된다.

**C. 오류·복귀**
1. 잘못된 주소 → "없음" 화면 → 홈으로.
2. 렌더 오류 → 오류 화면 → 다시 시도 또는 홈으로.

## 4. 영역별 기능 정의 및 정책

### 4.1 언어 / 지역 (i18n)
- **목적:** 영어·한국어를 제공하고 사용자가 직접 전환하게 한다.
- **구성 · 주요 기능:** 상단 내비의 언어 선택기(지구본 + 현재 언어 코드 + 선택 목록). 모바일용 선택기 별도 제공.
- **정책 · 규칙:**
  - **지원 언어:** 영어(기본)·한국어 2종.
  - **기본 언어 고정(프로토타입):** 첫 방문은 브라우저 언어와 무관하게 항상 영어로 시작한다(자동 감지 비활성). → §7
  - **수동 전환:** 언어를 바꾸면 보던 페이지를 유지한 채 선택 언어로 다시 표시한다(주소에 언어가 반영됨, 기본 언어는 접두사 없이).
  - **번역 출처:** 화면 문구는 언어별 번역 자원에서 가져온다(코드에 문구를 하드코딩하지 않는다).
- **상태별 표시:** 영어 / 한국어.

### 4.2 전역 내비게이션 (상단)
- **목적:** 어디서나 주요 영역과 계정 동작에 접근하게 한다.
- **구성 · 주요 기능:**
  - **로고:** 홈으로.
  - **탭:** 플래너 · 경험 · 스토리. 현재 위치한 영역은 활성 표시(경험 탭은 가이드 영역에서도 활성).
  - **언어 선택기 · 계정 영역:** 비로그인은 "로그인" + 계정 아이콘, 로그인은 계정 메뉴(이름·이메일·내 일정·도움말·로그아웃). 자세한 계정 동작은 [auth](./01_auth.md).
  - **모바일:** 탭이 계정 메뉴 안으로 들어간다.
- **정책 · 규칙:**
  - **깜빡임 방지:** 로그인 여부가 확정되기 전에는 로그인/계정 UI 노출을 보류한다(→ [auth](./01_auth.md)).
  - **메뉴 닫힘:** 계정 메뉴는 외부 클릭·ESC·페이지 이동 시 닫힌다.
  - **활성 표시:** 현재 영역 탭에 활성 상태와 보조기술용 현재 위치 표시를 준다.
  - **도움말 링크 미동작:** 계정 메뉴의 "도움말"은 현재 연결된 페이지가 없다. → §7
- **상태별 표시:** 상태 미확정(보류) / 비로그인 / 로그인 / 모바일.

### 4.3 푸터
- **목적:** 제품·회사·지원 정보 묶음과 브랜드 정보를 제공한다.
- **구성 · 주요 기능:** 브랜드(이름·태그라인) + 3개 컬럼(제품 · 회사 · 지원) 링크 + 하단 저작권/태그라인.
- **정책 · 규칙:**
  - 결제 완료 화면에서는 푸터를 숨긴다.
  - **링크 미동작:** 현재 푸터의 모든 링크(제품·회사·지원, 도움말·약관·개인정보 포함)는 실제 페이지로 연결되지 않는다. → §7
- **상태별 표시:** 표시 / (결제 완료 화면) 숨김.

### 4.4 화면 이동 동작
- **목적:** 페이지 전환을 일관되게 한다.
- **정책 · 규칙:**
  - **상단 정렬:** 화면 이동 시 새 페이지를 맨 위에서 보여준다(스크롤을 위로 초기화).
  - **딥링크:** 목록·위저드는 주소의 값으로 초기 상태를 채운다(도시·카테고리·검색어·날짜 등). 각 값의 의미는 해당 도메인 문서(특히 [experience](./04_experience.md)·[planner](./03_planner.md)).
- **상태별 표시:** 해당 없음.

### 4.5 통화 / 날짜 표기
- **목적:** 금액·날짜를 언어에 맞게 일관되게 보여준다.
- **정책 · 규칙:**
  - **통화:** 금액은 원화를 기준값으로 보관하고 표시할 때 변환한다. 한국어는 원화(₩)로, 그 외 언어는 달러($)로 보여준다.
  - **환율(프로토타입):** 달러 환산은 고정 환율을 쓰며 실시간 시세가 아니다. → §7
  - **날짜:** 날짜·기간은 언어에 맞는 형식으로 표시한다.
- **상태별 표시:** 한국어(₩) / 그 외($).

### 4.6 에러 화면
- **목적:** 렌더 오류에서도 복귀 경로를 준다.
- **구성 · 주요 기능:** 안내 아이콘 · 제목 · 부연 · "다시 시도" · "홈으로".
- **정책 · 규칙:** "다시 시도"는 화면을 다시 렌더링한다. 오류는 현재 콘솔에만 기록된다(외부 모니터링 없음). → §7
- **상태별 표시:** 오류(복구 액션 제공).

### 4.7 없음(404) 화면
- **목적:** 존재하지 않는 주소에서 막다른 길을 막는다.
- **구성 · 주요 기능:** 안내 아이콘 · 제목 · 부연 · "홈으로".
- **정책 · 규칙:** 알 수 없는 주소는 "없음" 화면으로 안내한다. (특정 항목 없음, 예: 없는 경험·일정·글은 각 도메인 문서의 빈 상태로 처리.)
- **상태별 표시:** 없음(홈 CTA).

### 4.8 접근성 (전역)
- **목적:** 키보드·보조기술 사용자가 전역 동작을 쓸 수 있게 한다.
- **정책 · 규칙:** 속성 수준 기준(라벨 연결, 포커스, 명도 대비, ARIA 등)은 [`/DESIGN.md`](../../DESIGN.md)의 접근성 체크리스트를 단일 기준으로 따른다. 전역 약속: 메뉴·모달은 ESC·외부 클릭으로 닫히고, 현재 위치는 보조기술에 전달되며, 화면 제목 구조를 유지한다.
- **상태별 표시:** 해당 없음.

## 5. 인수 조건 (Acceptance Criteria)

> 각 조건은 "이 동작이 이렇게 되면 기능 완성"을 판정하는 기준이다.

| ID | 관련 US | 인수 조건 (완성 기준) |
|---|---|---|
| AC-FND-01 | US-FND-01 | 모든 페이지 상단에 동일한 내비(로고·플래너·경험·스토리·계정)가 있고, 현재 영역 탭이 활성으로 표시된다. |
| AC-FND-02 | US-FND-02 | 언어 선택기에서 영어/한국어를 고르면 보던 페이지가 유지된 채 선택 언어로 다시 표시된다. |
| AC-FND-03 | US-FND-02 | 첫 방문은 브라우저 언어와 무관하게 영어로 시작한다. |
| AC-FND-04 | US-FND-03 | 금액이 한국어에서는 원화로, 그 외 언어에서는 달러로 표시되고, 날짜가 언어에 맞는 형식으로 표시된다. |
| AC-FND-05 | US-FND-04 | 존재하지 않는 주소로 들어가면 "없음" 화면과 홈으로 가는 CTA가 표시된다. |
| AC-FND-06 | US-FND-05 | 렌더 오류가 나면 오류 화면에 "다시 시도"와 "홈으로"가 표시되고, 다시 시도하면 화면을 복구하려 시도한다. |
| AC-FND-07 | US-FND-06 | 페이지를 이동하면 새 페이지가 화면 맨 위에서 보인다. |
| AC-FND-08 | US-FND-07 | 내비 탭·계정 메뉴·언어 선택기를 키보드로 조작할 수 있고, 메뉴·모달은 ESC와 외부 클릭으로 닫힌다. |
| AC-FND-09 | US-FND-08 | 모든 페이지(결제 완료 화면 제외) 하단에 제품·회사·지원 묶음과 브랜드 정보를 담은 푸터가 표시된다. |

## 6. 예외 처리 & 엣지 케이스

| 상황 | 기대 동작 |
|---|---|
| 알 수 없는 주소 | "없음"(404) 화면 + 홈 CTA. |
| 지원하지 않는 언어 주소 | 기본 언어(영어) 기준으로 처리된다. |
| 렌더 오류 발생 | 오류 화면(다시 시도/홈) 표시, 오류는 콘솔 기록. → §7 |
| 결제 완료 화면 | 푸터를 숨긴다. |
| 언어 전환 후 | 같은 페이지가 선택 언어로 유지된다(다른 곳으로 튕기지 않음). |
| 푸터/도움말 링크 클릭 | 현재 연결된 페이지가 없어 이동하지 않는다. → §7 |
| 계정 메뉴 열린 상태로 페이지 이동 | 메뉴가 자동으로 닫힌다. |

## 7. TBD / 정책 공백

> 현재 비어 있는 정책과 프로덕션 전환 시 결정할 항목. (결정권자·기한: _TBD_)

1. **브라우저 언어 자동 감지 비활성 (프로토타입)** - 첫 방문이 항상 영어로 시작한다. 프로덕션에서 방문자 언어 협상(Accept-Language) 여부 결정 필요.
2. **고정 환율** - 달러 환산이 고정 환율이고 실시간 시세가 아니다. 실제 환율·통화 표시 정책 필요.
3. **푸터·도움말 링크 미동작 (중요)** - 푸터의 제품·회사·지원 링크와 계정 메뉴의 "도움말"이 연결된 페이지가 없다. 정적 페이지(소개·약관·개인정보·고객지원 등) 작성·연결 필요. ([auth](./01_auth.md) §7의 약관 동의와 연계)
4. **오류 모니터링 부재** - 오류가 콘솔에만 기록되고 외부 수집/알림이 없다. 모니터링 연동 정책 필요.
5. **언어 범위·번역 완성도** - 현재 2개 언어만 지원한다. 추가 언어·번역 누락 점검·문구 현지화 품질 정책 필요.
6. **항목 없음 vs 주소 없음 구분** - 없는 경험·일정·글은 각 도메인의 빈 상태로, 알 수 없는 주소는 404로 처리한다. 두 경로의 일관된 카피·동작 정합 필요.
