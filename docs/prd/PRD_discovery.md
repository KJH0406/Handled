# PRD — 탐색 & 검색 (Discovery)

> **한 줄 요약:** 게스트가 로그인 없이 경험을 둘러보고 검색하며, 홈에서 핵심 퍼널(일정 플래너·경험·스토리)로 분기한다.
> **상태:** 🟡 초안(검토 요청)
> **작성 기준:** 하이브리드
> **관련 라우트:** `/`(홈), `/experiences`(경험 탐색)
> **관련 PRD:** [planner](./PRD_planner.md)(히어로 프리뷰·주요 CTA·관심사) · [experience](./PRD_experience.md)(경험 상세·출시 전 상태) · [content](./PRD_content.md)(스토리) · [foundation](./PRD_foundation.md)(검색·필터 UX·접근성)
> **범위 메모:** 가이드 탐색(가이드 목록 `/guides`·프로필)은 **현 단계 제외(보류)** — 추후 `PRD_guide`. 본 문서는 _경험 탐색 + 홈 진입점_ 만 다룬다.

---

## 1. 기능 배경 및 목적

### 배경 / 문제

방문자 대부분은 가입 의사가 정해지지 않은 채 들어온다. 첫 화면에서 제품 가치를 빠르게 전달하지 못하거나, "무엇을 할 수 있는지"가 모호하면 이탈한다. 또한 경험이 쌓일수록 원하는 것을 _찾는_ 비용이 커진다.

### 목적 / 목표

- **가치 전달 & 분기:** 홈에서 Handled가 무엇인지 한눈에 전하고, 핵심 행동(일정 만들기 · 경험 둘러보기 · 스토리 읽기)으로 자연스럽게 분기시킨다.
- **퍼널 수렴:** 발견 동선의 주요 CTA를 플래그십(일정 플래너)으로 수렴시킨다.
- **마찰 없는 탐색:** 로그인 없이 경험을 도시·카테고리로 좁히고 키워드로 검색해 상세까지 도달하게 한다.

### 성공의 정의 · 비목표(Non-goals)

- **성공:** 방문자가 홈에서 가치를 이해하고 → 플래너 또는 경험 탐색으로 진입 → (탐색의 경우) 필터/검색으로 원하는 경험 상세에 도달.
- **비목표(이번 범위 밖):** 가이드 탐색, 결과 정렬·페이지네이션, 개인화 추천, 위시리스트 저장. (→ §7)

## 2. 유저 스토리 (User Story)

**페르소나:** **여행자(Traveler)** — Handled로 한국 여행을 계획·예약하는 사람. 로그인 여부는 *상태*이지 페르소나가 아니며, 탐색·홈은 로그인과 무관하게 동일하게 이용한다.

| ID         | 스토리                                                                                 |
| ---------- | -------------------------------------------------------------------------------------- |
| US-DISC-01 | 여행자로서, 홈에서 Handled가 무엇이고 다음에 무엇을 할 수 있는지 빠르게 이해하고 싶다. |
| US-DISC-02 | 여행자로서, 홈에서 바로 '일정 만들기'로 진입하고 싶다.                                 |
| US-DISC-03 | 여행자로서, 어떤 경험들이 있는지 한 곳에서 둘러보고 싶다.                              |
| US-DISC-04 | 여행자로서, 도시·카테고리로 경험을 좁히고 키워드로 검색하고 싶다.                      |
| US-DISC-05 | 여행자로서, 마음에 드는 경험의 상세 정보로 이동하고 싶다.                              |
| US-DISC-06 | 여행자로서, 홈에서 인기 스토리를 발견해 읽으러 가고 싶다.                              |
| US-DISC-07 | 여행자로서, 필터를 한 번에 초기화하거나 검색 결과가 없을 때 쉽게 회복하고 싶다.        |

## 3. 핵심 사용자 플로우

**A. 홈 진입 → 분기**

1. 방문자가 홈 진입 → 히어로에서 가치와 일정 결과 미리보기 확인.
2. 의도에 따라 분기: **일정 만들기**(→ [planner](./PRD_planner.md)) · **경험 둘러보기**(→ §4.2) · **스토리 읽기**(→ [content](./PRD_content.md)).

**B. 경험 탐색 → 상세**

1. 경험 탐색 진입 → 도시·카테고리 필터 또는 키워드 검색.
2. 결과 그리드에서 경험 선택 → **경험 상세**로 이동(→ [experience](./PRD_experience.md)).
3. 결과가 없으면 빈 상태에서 필터 초기화로 회복.

**C. 딥링크 진입**

1. 도시/카테고리/검색어가 포함된 링크로 진입 → 해당 조건이 미리 적용된 목록이 열린다.

## 4. 화면별 기능 정의 및 정책

### 4.1 홈 — `/`

- **목적:** 제품 가치를 전달하고 핵심 퍼널로 분기시킨다.
- **진입 경로:** 로고/직접 진입, 내비.
- **구성 · 주요 기능:**
  - **히어로** — 카피 + '일정 만들기' CTA + **일정 결과 미리보기**(플래너 산출물 형태의 프리뷰). → [planner](./PRD_planner.md)
  - **신뢰 지표 통계** — 누적 여행자·가이드 수·평균 평점·도시 수 등 마케팅 수치.
  - **추천 경험(3개)** — 카드 그리드. **"출시 예정(Launching soon)"으로 표기**되며 "전체 보기"는 경험 탐색으로 이동. → [experience](./PRD_experience.md)
  - **스토리 그리드** — 콘텐츠 카드 + "전체 보기"(스토리). → [content](./PRD_content.md)
  - **플래너 안내 + CTA** — 3단계 설명과 일정 만들기 CTA.
  - **"진짜 한국" 가치 카드(3종)** — 검증된 호스트/테마 경험/현지 스토리 가치 소구.
- **정책 · 규칙:**
  - 모든 주요 CTA('일정 만들기' 등)는 **플래너 생성으로 수렴**한다.
  - 추천 경험은 **출시 예정 상태**로 노출한다(경험 출시 전 정책: [experience](./PRD_experience.md)).
  - 추천 경험 선정은 현재 **고정 3개(개인화·큐레이션 없음)**. → §7
- **상태별 표시:** 정적(단일 상태). 로그인 여부와 무관하게 동일 노출.

### 4.2 경험 탐색 — `/experiences`

- **목적:** 전체 경험을 검색·필터로 둘러보고 상세로 진입한다.
- **진입 경로:** 내비 'Experiences', 홈 추천 경험 "전체 보기", 딥링크.
- **구성 · 주요 기능:**
  - **인트로** — 제목 + 전체 경험 개수 안내.
  - **검색** — 키워드 입력(입력이 멈추면 짧은 지연 후 반영) + 입력 지우기.
  - **필터** — 도시 / 카테고리 선택.
  - **결과 요약 + 필터 초기화** — 활성 필터에 맞는 결과 문구, 조건이 있을 때 초기화 버튼.
  - **결과 그리드 / 빈 상태** — 경험 카드(호스트명 동반) 또는 결과 없음 안내(초기화 CTA).
- **정책 · 규칙:**
  - **도시 필터**는 호스트가 활동하는 도시 기준으로 거른다. **현재 선택지는 4곳(서울·부산·제주·인천)으로 제한**된다(전체 도시 대비 일부). → §7
  - **검색**은 경험 제목·요약·카테고리와 호스트명·도시를 **부분 일치**로 찾는다. **현재 대소문자를 구분**한다(프로토타입). → §7
  - **필터·검색 변경은 화면에 즉시 반영**되나 **주소(URL)에는 반영되지 않는다.** 딥링크로 들어온 초기 조건만 적용된다(공유 시 필터 유지 안 됨). → §7
  - **결과 요약 문구**는 활성 필터 조합(도시만 / 카테고리만 / 둘 다 / 없음)에 따라 달라진다.
  - 도시·카테고리·검색 중 **하나라도 활성이면** "필터 초기화"가 노출된다.
- **상태별 표시:** 기본(전체) / 결과 없음(빈 상태) / 딥링크 프리필터.

## 5. 인수 조건 (Acceptance Criteria)

> 각 조건은 "이 동작이 이렇게 되면 기능 완성"을 판정하는 기준이다.

| ID         | 관련 US        | 인수 조건 (완성 기준)                                                                                             |
| ---------- | -------------- | ----------------------------------------------------------------------------------------------------------------- |
| AC-DISC-01 | US-DISC-02     | 홈의 '일정 만들기'(히어로·플래너 CTA)를 누르면 플래너 생성 화면으로 이동한다.                                     |
| AC-DISC-02 | US-DISC-03, 06 | 홈 추천 경험의 "전체 보기"를 누르면 경험 탐색으로, 스토리의 "전체 보기"를 누르면 스토리 목록으로 이동한다.        |
| AC-DISC-03 | US-DISC-04     | 경험 탐색에서 도시나 카테고리를 선택하면 해당 조건에 맞는 경험만 즉시 추려져 표시된다.                            |
| AC-DISC-04 | US-DISC-04     | 검색어를 입력하면 짧은 지연 후, 제목·요약·카테고리·호스트명·도시에 부분 일치하는 경험만 표시된다.                 |
| AC-DISC-05 | US-DISC-07     | 도시·카테고리·검색 중 하나라도 활성이면 "필터 초기화"가 나타나고, 누르면 모든 조건이 풀려 전체 목록으로 돌아간다. |
| AC-DISC-06 | US-DISC-07     | 조건에 맞는 경험이 하나도 없으면 빈 상태 안내와 초기화 CTA가 표시된다.                                            |
| AC-DISC-07 | US-DISC-05     | 경험 카드를 선택하면 해당 경험 상세 화면으로 이동한다.                                                            |
| AC-DISC-08 | US-DISC-04     | 도시·카테고리·검색어가 포함된 링크로 진입하면 그 조건이 미리 적용된 상태로 목록이 열린다.                         |
| AC-DISC-09 | US-DISC-04     | 결과 요약 문구가 활성 필터(도시만/카테고리만/둘 다/없음)에 맞게 표시된다.                                         |
| AC-DISC-10 | US-DISC-01     | 홈은 가치 소개·추천 경험·스토리·플래너 안내 섹션을 포함해 제품 가치와 다음 행동을 전달한다.                       |

## 6. 예외 처리 & 엣지 케이스

| 상황                                       | 기대 동작                                                                            |
| ------------------------------------------ | ------------------------------------------------------------------------------------ |
| 검색 결과 0건                              | 빈 상태 안내 + 초기화 CTA 표시.                                                      |
| 검색어 대소문자 불일치(예: `seoul`)        | 현재 매칭되지 않음(대소문자 구분). → §7                                              |
| 빠른 연속 타이핑                           | 입력이 멈춘 뒤에만 결과가 갱신된다(마지막 입력 기준).                                |
| 입력 지우기 후                             | 검색 조건이 해제되어 (다른 필터 범위 내) 전체로 복귀.                                |
| 딥링크에 필터 옵션에 없는 값이 들어온 경우 | 해당 값으로 안전하게 처리되며 화면이 깨지지 않는다(결과 없음 또는 무시).             |
| 결과 0건 상태에서 필터 초기화              | 전체 목록으로 복귀.                                                                  |
| 출시 예정(추천) 경험 카드 선택             | 상세로 이동(상세에서는 예약 대신 출시 알림 신청: [experience](./PRD_experience.md)). |

## 7. TBD / 정책 공백

> 하이브리드 기준: 현재 비어 있는 정책과 프로덕션 전환 시 결정할 항목. (결정권자·기한: _TBD_)

1. **도시 필터 범위** — 경험 탐색의 도시 선택지가 4곳(서울·부산·제주·인천)으로 제한된다. 도메인 전체 도시 대비 일부이며, 확장 기준·노출 정책 필요.
2. **검색 품질** — 현재 대소문자를 구분하고 부분 문자열 일치만 지원한다. 대소문자 무시·동의어·다국어(한/영) 검색·오타 허용 정책 필요.
3. **필터 상태 URL 미동기화** — 필터/검색을 바꿔도 주소에 반영되지 않아 공유·뒤로가기 시 상태가 유지되지 않는다. 딥링크 동기화 정책 필요.
4. **정렬·페이지네이션 부재** — 결과 정렬(인기/평점/가격 등)과 다량 결과 처리(페이징/무한 스크롤) 정책 미정.
5. **개인화·큐레이션 부재** — 홈 추천 경험은 고정 노출(개인화·랭킹 없음). 추천 선정 기준 필요.
6. **위시리스트/찜 정책** — 경험을 저장/찜하는 기능의 제공 여부·동작 미정.
7. **홈 통계 수치 출처** — 신뢰 지표 통계가 실제 데이터와 연동되는지, 표기값인지 확정 필요.
8. **가이드 탐색 보류** — 가이드 목록 `/guides`·프로필은 현 단계 제외. 추후 `PRD_guide`에서 정의.
