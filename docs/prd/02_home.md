**한 줄 요약:** 방문자가 홈에서 Handled의 가치를 빠르게 이해하고, 핵심 퍼널(일정 플래너 / 경험 / 스토리)로 분기한다.

## 1. 기능 배경 및 목적

### 배경 / 문제
홈은 첫 접점이다. 제품 가치와 "다음에 할 수 있는 것"이 즉시 와닿지 않으면 방문자는 이탈한다.

### 목적 / 목표
- **가치 전달:** Handled가 무엇인지(검증된 현지 호스트·테마 경험·AI 일정)를 한눈에 전한다.
- **퍼널 분기:** 방문자를 의도에 맞는 다음 행동(일정 만들기 / 경험 둘러보기 / 스토리 읽기)으로 보낸다. 주요 CTA는 플래그십인 일정 플래너로 수렴한다.

### 성공의 정의 · 비목표(Non-goals)
- **성공:** 방문자가 홈에서 가치를 이해하고 플래너 또는 경험·스토리로 진입한다.
- **비목표(다른 스펙에서 다룸):** 경험 목록·검색 자체는 [experience](./04_experience.md), 스토리 목록은 [stories](./05_stories.md), 일정 생성 로직은 [planner](./03_planner.md). 홈은 이들로 가는 진입점만 책임진다.

## 2. 유저 스토리 (User Story)

**페르소나:** **여행자(Traveler)** - Handled로 한국 여행을 계획·예약하는 사람. 로그인 여부는 *상태*이지 페르소나가 아니며, 홈은 로그인과 무관하게 동일하게 노출된다.

| ID | 스토리 |
|---|---|
| US-HOME-01 | 여행자로서, 홈에서 Handled가 무엇이고 다음에 무엇을 할 수 있는지 빠르게 이해하고 싶다. |
| US-HOME-02 | 여행자로서, 홈에서 바로 일정 만들기로 진입하고 싶다. |
| US-HOME-03 | 여행자로서, 어떤 경험이 있는지 맛보기로 보고 더 보러 가고 싶다. |
| US-HOME-04 | 여행자로서, 인기 스토리를 발견해 읽으러 가고 싶다. |
| US-HOME-05 | 여행자로서, Handled의 신뢰 요소와 작동 방식(3단계)을 이해하고 싶다. |

## 3. 핵심 사용자 플로우

**홈 진입 → 분기**
1. 방문자가 홈에 진입해 히어로에서 가치와 일정 결과 미리보기를 본다.
2. 의도에 따라 분기한다: **일정 만들기**(→ [planner](./03_planner.md)) · **경험 둘러보기**(→ [experience](./04_experience.md)) · **스토리 읽기**(→ [stories](./05_stories.md)).

## 4. 화면별 기능 정의 및 정책

### 4.1 홈 `/`
- **목적:** 가치를 전달하고 핵심 퍼널로 분기시킨다.
- **진입 경로:** 로고/직접 진입, 전역 내비.
- **구성 · 주요 기능 (위에서 아래로):**
  - **히어로** - 헤드라인 + 일정 만들기 CTA + 일정 결과 미리보기(플래너 산출물 형태). → [planner](./03_planner.md)
  - **신뢰 지표 통계** - 누적 여행자·가이드 수·평균 평점·도시 수 등.
  - **추천 경험(3개)** - 카드 그리드. "출시 예정(Launching soon)"으로 표기. "전체 보기"는 경험 탐색으로 이동. → [experience](./04_experience.md)
  - **스토리 그리드** - 콘텐츠 카드 + "전체 보기"(스토리). → [stories](./05_stories.md)
  - **플래너 안내 + CTA** - 3단계 설명과 일정 만들기 CTA.
  - **"진짜 한국" 가치 카드(3종)** - 검증된 호스트 / 테마 경험 / 현지 스토리.
- **정책 · 규칙:**
  - 모든 주요 CTA('일정 만들기' 등)는 **플래너 생성으로 수렴**한다.
  - 추천 경험은 **출시 예정 상태**로 노출한다(상세 동작은 [experience](./04_experience.md)).
  - 추천 경험은 현재 **고정 3개**다(개인화·큐레이션 없음). → §7
  - 신뢰 지표 통계는 마케팅 표기값이다. → §7
- **상태별 표시:** 정적(단일 상태). 로그인 여부와 무관하게 동일 노출.

## 5. 인수 조건 (Acceptance Criteria)

> 각 조건은 "이 동작이 이렇게 되면 기능 완성"을 판정하는 기준이다.

| ID | 관련 US | 인수 조건 (완성 기준) |
|---|---|---|
| AC-HOME-01 | US-HOME-02 | 히어로나 플래너 안내의 '일정 만들기' CTA를 누르면 플래너 생성 화면으로 이동한다. |
| AC-HOME-02 | US-HOME-03 | 추천 경험의 "전체 보기"를 누르면 경험 탐색 화면으로 이동한다. |
| AC-HOME-03 | US-HOME-04 | 스토리의 "전체 보기"나 개별 스토리 카드를 누르면 해당 스토리 화면으로 이동한다. |
| AC-HOME-04 | US-HOME-01, 05 | 홈에 히어로·통계·추천 경험·스토리·플래너 안내·가치 카드 섹션이 표시되어 제품 가치와 다음 행동을 전달한다. |
| AC-HOME-05 | US-HOME-03 | 홈의 추천 경험은 "출시 예정"으로 표기된다. |

## 6. 예외 처리 & 엣지 케이스

| 상황 | 기대 동작 |
|---|---|
| 출시 예정(추천) 경험 카드 선택 | 경험 상세로 이동한다(상세에서는 예약 대신 출시 알림 신청: [experience](./04_experience.md)). |
| 추천·스토리 데이터가 비어 있을 때 | 해당 섹션이 비어도 홈 레이아웃이 깨지지 않는다(현재 데이터는 항상 존재). |
| 로그인/비로그인 | 홈은 동일하게 노출된다(개인화 없음). |
