## 1. 기능 배경 및 목적

### 배경 / 문제

홈은 첫 접점이다. 제품 가치와 "다음에 할 수 있는 것"이 즉시 와닿지 않으면 여행자는 이탈한다.

### 목적 / 목표

- **가치 전달:** Handled가 무엇인지(검증된 현지 가이드·AI 일정 생성·테마 경험·한국 여행 스토리)를 한눈에 전한다.
- **퍼널 분기:**
  - 여행자를 의도에 맞는 다음 행동(일정 만들기 / 경험 둘러보기 / 스토리 읽기)으로 보낸다.
  - 주요 CTA는 플래그십인 일정 플래너로 수렴한다.

### 성공의 정의 · 비목표(Non-goals)

- **성공:** 여행자가 홈에서 가치를 이해하고 플래너 또는 경험·스토리로 진입한다.
- **비목표(다른 스펙에서 다룸):** 경험 목록·검색 자체는 [experience](./04_experience.md), 스토리 목록은 [stories](./05_stories.md), 일정 생성 로직은 [planner](./03_planner.md). 홈은 이들로 가는 진입점만 책임진다.

## 3. 핵심 사용자 플로우

**홈 진입 → 분기**

1. 여행자가 홈에 진입해 히어로에서 가치와 일정 결과 미리보기를 본다.
2. 의도에 따라 분기한다: **일정 만들기**(→ [planner](./03_planner.md)) · **경험 둘러보기**(→ [experience](./04_experience.md)) · **스토리 읽기**(→ [stories](./05_stories.md)).

## 4. 화면별 기능 정의 및 정책

### 4.1 홈 `/`

- **목적:** 가치를 전달하고 핵심 퍼널로 분기시킨다.
- **진입 경로:** 로고/직접 진입, 전역 내비.
- **구성 · 주요 기능:**
  - **히어로** : 헤드라인 + 일정 만들기 CTA + 일정 결과 미리보기(플래너 산출물 형태). → [planner](./03_planner.md)
  - **추천 경험** : 카드 그리드. "출시 예정(Launching soon)"으로 표기. "전체 보기"는 경험 탐색으로 이동. → [experience](./04_experience.md)
  - **스토리(Dispatches from Korea)** : 한국 여행 스토리를 카드로 보여 주고 전체 목록으로 보낸다. → [stories](./05_stories.md)
    - 작은 머리말 "DISPATCHES FROM KOREA"
    - 헤드라인 "Stories that make you want to book a flight."
    - 스토리 카드: 데스크탑 3개(첫 카드를 크게 강조하고 나머지 2개는 작게), 모바일 2개 노출. 카드는 이미지 배경 위에 카테고리 배지(좌상단) + 제목 + 날짜·읽는 시간(하단)을 얹는다.
    - "전체 보기"(All Stories): 데스크탑은 섹션 헤더 우측 버튼, 모바일은 카드 하단 전체폭 버튼으로 스토리 목록으로 이동한다.
  - **작동 방식(How Handled Works)** : Handled의 핵심 가치 3가지를 카드 3종으로 전달하고, 하단에 일정 만들기 CTA를 둔다.
    - 작은 머리말 "HOW HANDLED WORKS"
    - 헤드라인 "Everything you need. Nothing in the way." + 보조 문구 "한국 여행 전체를 한 곳에서, 첫 아이디어부터 마지막 추억까지."
    - 가치 카드 3종(번호 01 / 02 / 03):
      1. **몇 분 만에 완성되는 내 일정** : 목적지, 여행 스타일, 예산만 알려주면 Handled가 숙소, 교통, 현지 팁까지 담은 날짜별 계획을 만들어 준다.
      2. **인증된 현지 가이드** : 모든 가이드는 한국 정부 관광 자격을 가진 사람이다. 인기 SNS 계정이 아니라 검증된 전문가다.
      3. **관광객은 모르는 진짜 한국** : 현지인이 찾는 맛집, 잘 알려지지 않은 갤러리, 서울 사람들이 실제로 좋아하는 동네. 가이드북마다 나오는 곳이 아닌 진짜 경험.
    - 하단 일정 만들기 CTA(예: "Create a New Trip")와 보조 문구("무료로 시작, 신용카드 불필요").
- **정책 · 규칙:**
  - 모든 주요 CTA('일정 만들기' 등)는 **플래너 생성으로 수렴**한다.
  - 추천 경험은 **출시 예정 상태**로 노출한다(상세 동작은 [experience](./04_experience.md)).
  - 추천 경험은 현재 3~4개 노출한다(잠정값, 최종 개수·노출 정책은 섹션7에서 확정). → 섹션7 참고
- **상태별 표시:** 정적(단일 상태). 로그인 여부와 무관하게 동일 노출.

## 5. 인수 조건 (Acceptance Criteria)

| ID         | 관련 US        | 인수 조건 (완성 기준)                                                                                     |
| ---------- | -------------- | --------------------------------------------------------------------------------------------------------- |
| AC-HOME-01 | US-HOME-02     | 히어로나 작동 방식 섹션의 '일정 만들기' CTA를 누르면 플래너 생성 화면으로 이동한다.                       |
| AC-HOME-02 | US-HOME-03     | 추천 경험의 "전체 보기"를 누르면 경험 탐색 화면으로 이동한다.                                             |
| AC-HOME-03 | US-HOME-04     | 스토리의 "전체 보기"나 개별 스토리 카드를 누르면 해당 스토리 화면으로 이동한다.                           |
| AC-HOME-04 | US-HOME-01, 05 | 홈에 히어로·추천 경험·스토리·작동 방식(가치 카드 3종) 섹션이 표시되어 제품 가치와 다음 행동을 전달한다. |
| AC-HOME-05 | US-HOME-03     | 홈의 추천 경험은 "출시 예정"으로 표기된다.                                                                |

## 6. 예외 처리 & 엣지 케이스

| 상황                              | 기대 동작                                                                                   |
| --------------------------------- | ------------------------------------------------------------------------------------------- |
| 출시 예정(추천) 경험 카드 선택    | 경험 상세로 이동한다(상세에서는 예약 대신 출시 알림 신청:[experience](./04_experience.md)). |

| 로그인/비로그인                   | 홈은 동일하게 노출된다(개인화 없음).                                                        |
