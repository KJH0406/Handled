# 05. 스토리 (Stories)

여행자가 한국 여행 콘텐츠(블로그 글)를 카테고리·토픽 태그로 둘러보고, 추천 글로 이어 읽으며, 여행 영감을 얻게 한다.

| 항목            | 내용                                                                                             |
| --------------- | ------------------------------------------------------------------------------------------------ |
| **상태**        | 🟡 초안(검토 요청)                                                                               |
| **작성 기준**   | 현재 구현된 동작 기준 (미구현·정책 공백은 섹션7에 분리)                                          |
| **관련 라우트** | `/stories`(목록) · `/stories/[storyId]`(상세)                                                    |
| **범위 메모**   | 콘텐츠 읽기 전용 도메인. 댓글·좋아요·공유·구독 같은 참여 기능은 현 단계 제외(→ 섹션7).           |
| **관련 PRD**    | [home](./02_home.md)(홈의 스토리 진입) · [foundation](./07_foundation.md)(언어·내비·접근성·에러) |

## 1. 기능 배경 및 목적

### 배경 / 문제

경험·일정만으로는 여행 동기가 충분히 자극되지 않는다. 여행자는 "무엇을, 왜, 어떻게" 즐기는지에 대한 맥락과 영감을 원한다. 스토리는 현지 시선의 읽을거리로 이 빈자리를 채우고, 둘러보다 자연스럽게 경험·일정으로 관심이 번지게 하는 진입 콘텐츠다.

### 목적 / 목표

- **영감·맥락 제공:** 동네·음식·문화·자연 등 주제별 글로 여행 결정을 돕는 맥락을 준다.
- **가벼운 탐색:** 카테고리와 토픽 태그로 관심 주제만 빠르게 골라 읽게 한다.
- **경험으로 잇기:** 한 글을 다 읽으면 글 컨셉과 맞는 경험으로 자연스럽게 연결해 영감을 전환으로 잇는다.

### 성공의 정의 · 비목표(Non-goals)

- **성공:** 여행자가 목록에서 관심 주제를 골라 글을 열고, 끝까지 읽은 뒤 글과 맞는 경험으로 이어진다.
- **비목표(이번 범위 밖):** 글 작성·관리(CMS), 댓글·좋아요·북마크, 실제 공유, 뉴스레터 구독 처리, 본문 내 실제 사진/미디어, 검색·페이지네이션. (→ 섹션7)

## 2. 유저 스토리 (User Story)

**페르소나:** **여행자(Traveler)** - Handled로 한국 여행을 계획·예약하는 사람. 스토리는 로그인 없이 누구나 읽을 수 있어 로그인 상태와 무관하다.

| ID          | 스토리                                                                      |
| ----------- | --------------------------------------------------------------------------- |
| US-STORY-01 | 여행자로서, 어떤 여행 글들이 있는지 한눈에 둘러보고 싶다.                   |
| US-STORY-02 | 여행자로서, 관심 있는 카테고리의 글만 골라 보고 싶다.                       |
| US-STORY-03 | 여행자로서, 토픽(태그)으로 글을 좁혀 보고 싶다.                             |
| US-STORY-04 | 여행자로서, 추천(주요) 글과 최신 글을 먼저 보고 싶다.                       |
| US-STORY-05 | 여행자로서, 한 글을 열어 처음부터 끝까지 편하게 읽고 싶다.                  |
| US-STORY-06 | 여행자로서, 글을 다 읽은 뒤 그 글과 맞는 경험으로 자연스럽게 이어지고 싶다. |
| US-STORY-07 | 여행자로서, 글에 달린 토픽으로 같은 주제의 다른 글을 찾고 싶다.             |
| US-STORY-08 | 여행자로서, 조건에 맞는 글이 없을 때 그 사실과 빠져나갈 방법을 알고 싶다.   |

## 3. 핵심 사용자 플로우

**A. 탐색 (목록)**

1. 목록 진입(내비, 홈의 스토리 진입, 딥링크).
2. 주요 글·최신 글을 먼저 본다.
3. 카테고리 또는 토픽 태그로 좁힌다 → 글 그리드가 갱신된다.
4. 결과가 없으면 빈 상태 안내 → 필터 초기화로 복귀.
5. 글 카드를 선택해 상세로 이동.

**B. 읽기 (상세)**

1. 제목·카테고리·날짜·읽는 시간과 요약을 본 뒤 본문을 읽는다.
2. 하단 토픽 태그를 눌러 같은 주제의 목록으로 이동.
3. 글 컨셉과 맞는 추천 경험으로 이어진다(→ [experience](./04_experience.md)).

## 4. 화면별 기능 정의 및 정책

### 4.1 스토리 목록 - `/stories`

- **목적:** 전체 글을 주요/최신/카테고리/토픽으로 둘러보게 한다.
- **진입 경로:** 전역 내비, 홈의 스토리 진입, 카테고리·토픽이 담긴 딥링크.
- **구성 · 주요 기능:**
  - **인트로:** 키커·제목·소개문.
  - **주요 영역:** 추천(주요) 글 큰 카드 + 옆에 "최신" 글 묶음. _(추천 글 선정·정렬 기준은 섹션7 참고)_
  - **카테고리 칩:** 카테고리 선택 줄("전체" 포함).
  - **토픽 태그:** 글들에 쓰인 토픽 태그 묶음(빈도순 정렬).
  - **글 그리드:** 현재 조건에 맞는 글 카드(추천 글은 그리드에서 제외).
  - **빈 상태:** 결과가 0개면 안내 제목·부연과 초기화 CTA.
- **정책 · 규칙:**
  - **단일 필터:** 카테고리와 토픽은 **동시에 하나만** 적용된다. 카테고리를 고르면 토픽이 해제되고, 토픽을 고르면 카테고리가 "전체"로 돌아간다. 같은 토픽을 다시 누르면 해제된다.
  - **딥링크 프리필:** 주소의 카테고리·토픽 값으로 초기 상태를 채운다.
- **상태별 표시:** 기본(전체) / 카테고리·토픽 적용 / 빈 상태(0건).

### 4.2 스토리 상세 - `/stories/[storyId]`

- **목적:** 한 글을 편히 읽고, 토픽·관련 경험으로 이어지게 한다.
- **진입 경로:** 목록 카드, 홈 카드, 토픽 태그, 공유·딥링크.
- **구성 · 주요 기능:**
  - **돌아가기:** 상단 돌아가기(브레드크럼).
  - **머리말:** 카테고리 배지 · 날짜 · 읽는 시간 / 제목 / 요약.
  - **대표 비주얼:** 색상 배경 블록(실제 사진 아님).
  - **본문:** 문단 단위 텍스트.
  - **토픽:** 글에 달린 토픽 태그(누르면 해당 토픽으로 목록 이동).
  - **관련 경험:** 이 글의 컨셉(카테고리·토픽)과 맞는 추천 경험 카드(→ [experience](./04_experience.md)). 글을 읽은 흐름이 경험 탐색으로 이어지게 한다.
- **정책 · 규칙:**
  - **관련 경험 구성:** 글의 컨셉(카테고리·토픽)과 맞는 경험을 추천한다(최대 3개). 글-경험 매칭 기준은 추후 정의(→ 일정 생성·추천 알고리즘 문서).
  - **토픽 이동:** 토픽 태그를 누르면 그 토픽이 적용된 목록으로 이동한다.
  - **돌아가기 동작:** 블로그 글 목록으로 이동한다.
- **상태별 표시:** 정상 / **없음(잘못된·없는 글)** → 섹션4.3.

### 4.3 없는 글 처리

- **목적:** 잘못된·삭제된 글 주소에서 막다른 길을 만들지 않는다.
- **정책 · 규칙:** 존재하지 않는 글 주소로 들어가면 안내 문구와 홈으로 가는 CTA를 보여준다(빈 상태). 페이지 제목도 "찾을 수 없음" 취지로 표기된다.
- **상태별 표시:** 없음(안내 + 홈 CTA).

| AC-STORY-09 | US-STORY-06 | 상세 하단에 이 글과 맞는 추천 경험이(최대 3개) 표시되고, 누르면 해당 경험 상세로 이동한다.                 |
| AC-STORY-10 | US-STORY-01 | 존재하지 않는 글 주소로 들어가면 안내와 홈으로 가는 CTA가 표시된다.                                        |

## 6. 예외 처리 & 엣지 케이스

| 상황                       | 기대 동작                                                     |
| -------------------------- | ------------------------------------------------------------- |
| 카테고리·토픽 결과 0건     | 빈 상태 안내 + 초기화 CTA.                                    |
| 카테고리 선택 중 토픽 선택 | 토픽이 적용되고 카테고리는 "전체"로 전환(둘 동시 적용 안 됨). |
| 같은 토픽 재클릭           | 토픽이 해제되어 전체로 복귀.                                  |
| 관련 경험이 없는 경우      | 최대한 유사한 경험으로 표시한다.                              |
| 잘못된/삭제된 글 주소      | "없음" 안내 + 홈 CTA.                                         |

## 7. TBD / 정책 공백

> 현재 비어 있는 기능 및 정책과 프로덕션 전환 시 결정이 필요한 항목. (결정권자 : CPO)

1. **참여 기능 미지원** : 현재는 댓글, 좋아요, 북마크, 실제 공유 등 사용자의 콘텐츠 참여 기능이 제공되지 않음. 향후 이러한 기능의 도입 및 우선순위에 대한 검토가 필요함.
2. **글-경험 매칭 및 일정 연계** : 기존에는 후속 글을 제안하는 방식이었으나, 실제 블로그 글의 유입 목적과 서비스 이용 전환을 극대화하기 위해, 글 하단에 해당 글과 연관성 높은 경험 목록을 노출하도록 변경하였음.
3. **스토리 큐레이션 및 정렬 정책** : 추천(주요) 글은 현재 수동으로 지정하며, 목록은 고정된 순서로 노출됨. 앞으로 어떤 기준(큐레이션, 인기, 최신 등)에 따라 글을 추천·정렬할지에 대한 세부 정책 및 시스템화 필요.
4. **추천 글 중복 노출 정책** : 추천(주요)으로 강조된 글을 하단 글 목록(그리드)에 중복하여 노출할지 여부에 대한 정책 및 기준 확정 필요.
5. **SEO 및 공유용 메타데이터** : 검색 유입과 외부 공유를 고려하여, 각 글에 제목, 요약, OG(Open Graph) 태그 등 SEO 및 소셜 미디어 전용 메타데이터 설정 정책이 필요함. (구현 시점에 구체 가이드 작성 필요)
